# Weather App

A simple weather app that uses the Visual Crossing weather API to display weather information from anywhere in the world.

The app should display the following information;

1. General weather status i.e sunny, rainy, cloudy etc

2. A short sentence description of the weather

3. The temperature

4. A button to convert fahrenheit to celsius and vice-versa

5. A beautifully colored gradient on the whole of the page. A blue gradient preferred.

Additional features planned:

1. Match the input to the location with the most similar name vs what was actually searched to prevent strange locations being shown on the screen.

2. Add wind speed

3. Potential UI modifications to enhance user experience.

4. A favicon
